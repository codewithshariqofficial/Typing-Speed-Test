# Typing Speed Test

A simple web app to test your typing speed and accuracy, built with HTML, CSS, and JavaScript.

## Features

- 60-second countdown timer
- Real-time WPM (Words Per Minute) calculation
- Accuracy percentage tracking
- Error count tracking
- Character-by-character visual feedback (correct / incorrect / active)
- Restart test button

## How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start typing in the text box — the timer begins on your first keystroke.

No build step or dependencies required.

## Files

- `index.html` — Page structure
- `style.css` — Styling and responsive layout
- `script.js` — Typing logic, timer, and stats calculation

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or libraries)
