# Typing Speed Test

A lightweight, browser-based typing speed test that measures your typing speed and accuracy in real time. Type the displayed sentence as fast and as accurately as you can within 60 seconds and get instant feedback on your performance.

**Live Demo:** https://codewithshariqofficial.github.io/Typing-Speed-Test/

## Features

- 60-second countdown timer
- Real-time Words Per Minute (WPM) calculation
- Accuracy percentage tracking
- Live error count
- Character-by-character visual feedback (correct / incorrect / active)
- Restart test button
- Responsive layout for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or build tools)

## Getting Started

No installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/codewithshariqofficial/Typing-Speed-Test.git
   ```

2. Open `index.html` in any modern web browser.

3. Start typing in the input box — the timer begins on your first keystroke.
